ReelFlow Local Privacy Policy

Effective date: November 6, 2026

ReelFlow Local is a personal publishing tool that runs on the user's own Windows computer. It lets a user connect Instagram professional accounts and publish media selected by that user.

Data processed

The app processes the connected Instagram account ID, username, access token, media selected by the user, captions, cover images, schedules, and Instagram publishing results.

How data is used

Data is used only to show connected accounts, prepare requested posts, publish them to Instagram, and display local queue results. ReelFlow Local does not sell personal data or use it for advertising.

Storage and sharing

Access tokens are stored in Windows Credential Manager on the user's computer. Queue information and selected media are stored locally. During publishing, a temporary, unguessable media URL is made available so Meta can retrieve the selected media. No permanent ReelFlow cloud database is operated.

Retention and deletion

Users can disconnect an Instagram account from the ReelFlow Local panel, which removes its locally stored access token. Local media and queue records remain under the user's control and can be removed from the computer. See the data deletion instructions.

Contact

Questions can be submitted through the ReelFlow support page.
