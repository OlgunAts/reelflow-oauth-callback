ReelFlow Local Data Deletion Instructions

Last updated: November 6, 2026

ReelFlow Local stores account credentials and publishing data only on the user's own Windows computer.

Disconnect an Instagram account

  1. Open the ReelFlow Local panel.
  2. Find the Instagram account under Instagram accounts.
  3. Select the remove button next to that account.

This removes the account access token from Windows Credential Manager and removes the account from the local account list.

Remove local media and queue history

Because ReelFlow Local runs on the user's computer, the user controls the project data folder and can delete its local media and database after stopping the panel.

Revoke Meta access

The user can also revoke ReelFlow Local in Instagram or Meta account settings under connected apps and websites.

Help

Deletion questions can be submitted through the ReelFlow support page.
